# UX Audit

## Nielsen's 10 heuristics (checklist)
1. Visibility of system status (loading, progress, saved)
2. Match with real world (user language)
3. User control & freedom (undo, cancel, back)
4. Consistency & standards
5. Error prevention (constraints, confirmations)
6. Recognition over recall
7. Flexibility & efficiency (shortcuts, bulk actions, search)
8. Aesthetic & minimalist design
9. Help users recover from errors
10. Help & documentation

## Also check
Accessibility (WCAG 2.2 AA), responsive behavior, performance perception (skeletons, optimistic UI), empty/error states, onboarding, permissions clarity, copy quality, consistency of components.

## Finding format
`ID | Screen | Issue | Heuristic violated | Severity (0-4) | Evidence | Recommendation`

Severity: 4 blocker, 3 major, 2 minor, 1 cosmetic, 0 not an issue. Sort by severity, then by frequency of the affected task.

## Output
- Top 5 quick wins (high impact, low effort)
- Full findings table
- What's working well (keep)
- Suggested usability tests to confirm
Only report issues observed or inferable from provided material; label guesses as hypotheses.
