# Test Plan Template

1. **Objective & scope** – what and why; in-scope / out-of-scope features.
2. **References** – requirements, designs, user stories.
3. **Test types** – functional, regression, smoke/sanity, integration, API, UI, security, performance, usability, compatibility, UAT.
4. **Approach** – manual vs automated split, tools, techniques, test data strategy.
5. **Environments** – URLs, builds, devices/browsers, accounts/roles, third-party mocks.
6. **Entry criteria** – build deployed, smoke passes, test data ready.
7. **Exit criteria** – e.g. 100% P0/P1 executed and passed, no open Critical/Major, ≥95% overall pass.
8. **Risks & mitigations** – ranked by likelihood × impact.
9. **Roles & schedule** – who tests what, by when.
10. **Deliverables & metrics** – test cases, execution report, defect report; pass %, defect density, escape rate, coverage.
11. **Defect workflow** – New → Assigned → In Progress → Fixed → Retest → Closed / Reopened.

Keep it proportional: a small feature gets a one-page plan, not 20 pages.
